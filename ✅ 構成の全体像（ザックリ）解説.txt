③ CPUの手を決める部分：ランダム処理
js
コピーする
編集する
const hands = ["グー", "チョキ", "パー"];
const cpuHand = hands[Math.floor(Math.random() * 3)];
Math.random() で 0〜1のランダムな数を生成。

Math.floor(... * 3) で 0, 1, 2 のどれかに丸めて配列からCPUの手を選ぶ。

つまり 「CPUがランダムで手を選ぶ」処理。

④ 勝敗の判定：if文の地獄
js
コピーする
編集する
if (playerHand === cpuHand) {
  result = "あいこ";
  draw++;
} else if (
  (playerHand === "グー" && cpuHand === "チョキ") ||
  (playerHand === "チョキ" && cpuHand === "パー") ||
  (playerHand === "パー" && cpuHand === "グー")
) {
  result = "勝ち";
  win++;
} else {
  result = "負け";
  lose++;
}
プレイヤーとCPUの手を比較して勝ち/負け/あいこを判定。

それに応じて win, lose, draw を1増やす。

条件が読みにくい？それが正常。最初は丁寧にトレースすれば理解できる。
